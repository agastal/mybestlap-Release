# mybestlap changelog

Newest first. [Italiano](CHANGELOG.it.md)

## [0.6.0] - 2026-10-11

First public version: an overlay for Assetto Corsa EVO that records every lap with the setup used and shows, while you drive, how the setup in use compares with the best one.

### New
- Overlay on the game with the best setup and its lap, the live gap to the best lap, the setup in use, tyre and brake temperatures (average and peak), average and peak speed, fuel per lap and per minute.
- Three layouts (column, grid, bar), background transparency, measures to show, four fonts and sizes chosen in Settings, with the overlay following while you change them.
- Recognises the setup loaded or saved and unsaved changes too; a variant saved later takes the name with all its laps.
- Laps of setups deleted in the game leave the archive.
- Setup comparison: for each car and track best lap, median, sectors, temperatures, speed, fuel and balance.
- Shortcuts Ctrl+Shift+F7 (show/hide overlay) and Ctrl+Shift+F8 (place overlay), changeable.
- Updates: the app checks once a day and installs the new version in one click, or by itself with the game closed.
